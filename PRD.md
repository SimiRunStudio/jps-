# Asmaron Language & Multi-Subject Platform - V19 Release PRD

## Executive Overview
Asmaron v19 represents the ultimate commercial production build featuring **356 micro-features, systems, and UI components**.

## Key Architecture Pillars
1. **Full-Duplex WebRTC AI Voice Companion**: Sub-150ms audio latency with dynamic barge-in and conversational memory.
2. **Acoustic Phoneme & Formant Waveform Analyzer**: Syllable-level IPA matching, pitch contour analysis, and real-time visual feedback.
3. **Adaptive Diagnostic Placement Test**: Item Response Theory (IRT) diagnostic test to assess partial knowledge and auto-skip basic units.
4. **Practice Hub & SM-2 Spaced Repetition**: Free universal access for Mistakes Review, Words Flashcards, Speak, Listen, and Match Madness.
5. **Multi-Subject Ecosystem**: Integrated AI tutors for Language, Math, Music (piano), Chess (Stockfish-v16), and Duolingo English Test (DET).
6. **Ultra-Performance UI/UX Design System**: Deep Slate OLED dark theme (`#0F172A`), 60 FPS micro-interactions, stats header, and CEFR path nodes.
